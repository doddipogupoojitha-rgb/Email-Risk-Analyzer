# Email Risk Analyzer - Phishing Detection Tool

Build a script scanning email headers and body text for phishing indicators.

## Features
1. Parse raw email headers (Received, Return-Path, SPF, DKIM)
2. Scan body for suspicious links, domain spoofing, urgent keywords
3. Assign risk score 0-100
4. Generate Email Security Audit Report

## How to Run
python email_analyzer.py

## Output Includes
- SPF/DKIM authentication check
- Suspicious link detection
- Risk Score (0-100) and Verdict
- Complete Audit Report
